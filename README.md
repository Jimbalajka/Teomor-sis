# Teomor-sis

## Локальный запуск (VS Code)

**Единственная папка для `npm run dev`:**

```
Teomor-sis/Код/
```

1. File → Open Folder → **Код**
2. `npm install && npm run dev`
3. http://localhost:5173/?reset=1

**Признак новой версии:** зелёная полоска сверху «BUILD 2.2» + в шапке «v2.2».

❌ Не используй: `rpg-skill-tree-main/app/` (npm run dev там теперь выдаст ошибку).
