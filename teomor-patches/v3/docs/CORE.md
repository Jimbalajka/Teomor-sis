# ТЕОМОР — Ядро v3

Принцип: **за столом почти нет счёта. Игрок сам видит шансы. Бросок редкий и даёт случай. Глубина — в древе и приложении.**

За столом: **Квель · мастерство · условие сцены · к8 · Раны · Усталость · карты приёмов.**

v2 (`docs/core/CORE.md`) остаётся справочником. **SoT для новой линии — этот файл.**

---

## 0. Что убрано из разрешения v2

- Сложение `kN + навык` против DC 5…80
- Кость действия kN как сумма до 3к20 в проверках
- Отдельное «владение навыком» (профiciency) — заменено ступенью `нет`
- Уровни персонажа как ось проверки

Ось силы теперь: **Квель (1–10)** + **мастерство** + **условия сцены**.

---

## 1. Единая формула проверки

```
Если Квель выше уровня цели И нет особого условия → автоуспех (кости нет).
Иначе → к8 по сетке ступени навыка (или характеристики, если узкого навыка нет).
```

Игрок объявляет: свой Квель, ступень, что делает.  
Мастер вслух: уровень цели и есть ли **особое условие**.  
Игрок сам понимает: авто или к8 и какие грани успех.

### Особые условия (примеры)
Настороже · свидетели · магическая охрана · мастер внимания · святыня · цейтнот · сцена «на глазах двора».

Условие **форсит к8**, даже если Квель выше.  
Мастер не молчит «нет» — он называет условие.

### Цель без полного листа
NPC/замок/рецепт/тайна: **уровень 1–10** (+ ярлыки вроде `внимание: мастер`).  
Полный Квель — у героев, боссов, явных сил. Не у каждого стража.

---

## 2. Квель (1–10)

Квель — фундамент силы (не класс): лига, лимит усталости приёма, пассив/стойка.

- Шкала **1 → 10** (больше = сильнее). Шутка стола «у меня квель 8, у тебя 3» — легальна.
- Для проверки берётся **релевантный** Квель (воровство, разум, мощь, ремесло…).
- Сравнение: **Квель героя vs уровень цели**.

Квель отвечает: *в какой я лиге.*  
Мастерство отвечает: *насколько чисто в деле.*

---

## 3. Мастерство (навыки и характеристики)

Ступени:

`нет → новичок → ученик → эксперт → адепт → мастер → зверь`

Отдельного «владения» нет: `нет` = край лестницы.

### Сетка к8

| Ступень | Успех на | Провал |
|--|--|--|
| нет | только **8** | 1–7 |
| новичок | 7–8 | 1–6 |
| ученик | 6–8 | 1–5 |
| эксперт | 5–8 | 1–4 |
| адепт | 4–8 | 1–3 |
| мастер | 3–8 | 1–2 |
| зверь | провала нет | — |

**Зверь:** проверка «успел/нет» не кидается (или к8 только ради крита/ресурса). Неудача запрещена ступенью. Зверь — редкий кэпстоун древа, не норма середины кампании.

### Взрывы / криты на к8
- **1** → провал + взрыв: ещё раз 1 = **крит-провал**
- **8** → успех + взрыв: ещё раз 8 = **крит-успех**
- У **зверя** крит-провала нет

### Характеристики vs навыки
Одна сетка к8. Разница — ширина, не формула.

| | Мощь · Разум · Моторика · Стержень | Навык |
|--|--|--|
| Когда | быт, сопротивление, широкое давление без узкого навыка | конкретное дело |
| Потолок | чаще до адепта/мастера | до зверя (редко) |
| Узкий спор | уступает навыку | бьёт характеристику в нише |

Экспертное дело без нужного навыка (`нет`) — нельзя, кроме явного допуска Мастера + риск.

---

## 4. Вдохновение и Уныние

Крит-успех / крит-провал и отдельные эффекты карт кормят экономику:

- **Вдохновение** (игрок, макс 3): перекинуть к8 · снять Уныние · снять рану · 3 = крит-эффект по столу
- **Уныние** (Мастер, макс 3): форс условия · рана · ухудшить ступень на −1 к сетке на бросок

Длинный отдых сбрасывает оба (если стол не договорился иначе).

---

## 5. Способности старого типа (перевод)

| Было (d20 / v2) | v3 |
|--|--|
| крит с 19–20 | взрыв/крит с **7–8**, не только с 8 |
| преимущество / помеха | +1 / −1 ступень к сетке на бросок |
| переброс | перекинуть к8 раз за проверку |
| «кинь 3 кости, подменяй потом» | банк: заранее 3к8, записать грани; раз за проверку подменить бросок одной гранью (сжечь) |
| +N к навыку | +ступень(и) мастерства в древе |

---

## 6. Где броска нет (ролевая модель)

- Квель выше + нет условия → авто, сцена идёт от мастерства героя
- Аура/свободный эффект на цель заметно слабее (см. §8) → авто без кости и часто без усталости
- Фокус аспекта без «зубов» → фикшн, 0 усталости

Бросок нужен, когда есть **неуверенность или интересный риск** — иначе не кидать.

---

## 7. Здоровье, защита, бой

- **Раны (герой):** старт 2, потолок **6** (прокачка древом). Раны кончились → крит. состояние / смерть по столу.
- **NPC:** массовка 1–2 · обычный 2–3 · сюжетный 4–6 · босс 8–12 или фазы.
- **КБ** = 10 + Уклонение + Броня (приложение считает).
- Атака вне авто-ауры: та же формула §1 (Квель/навык боя vs уровень + КБ как якорь лиги цели). Пробил → раны по приёму/базе.
- Базовая атака без карты → 1 рана. Приём-карта → раны и эффекты сигила. Крит → +1 рана (если стол не сказал иначе).

---

## 8. Аура и три способа действовать

Аура привязана к **Квелю/мощи**, не к «уровню персонажа» v2.

- Цель на **2+ слабее** по лиге → свободные эффекты **авто**, без кости и часто без усталости
- Цель ±1 или сильнее → нужна проверка §1 или **приём**
- Против PC авто-эффект не навязывается — всегда есть защита/ответ

Три способа:
1. **Фокус** — 0 усталости, фикшн аспекта, без механических зубов
2. **Свободный эффект** — импровиз; на слабых авто; на равных/сильных слабо
3. **Приём (карта)** — усталость впечатана, гарантия/масштаб/статусы

## 9. Усталость · Квель · Аспект · Сигил · Инструмент

Без смены духа v2:

| Карта | Усталость | Роль |
|--|--|--|
| Инструмент | 0 | оружие/фокус |
| Квель | — | лимит усталости, ранг 1–10, пассив |
| Аспект | 1 | стихия/тип; импровизация фокусов |
| Сигил | 1+ | форма, раны, статусы |

Сумма аспекта+сигилов ≤ лимит квеля (считает приложение).  
Горячий каскад = Действие; холодный = Бонусное, слабее.  
Название/флавор пишет игрок.

---

## 10. Ход в бою

За раунд: **1 Действие + 1 Бонусное + 1 Малое + 1 Реакция**.  
Клетка = 1.5 м. Инициатива — карточная (колода на раунд), если стол использует.

## 12. Прогрессия и древо v3

**Уровня персонажа как оси проверки нет.**  
Растут: Квели, ступени мастерства, аспекты/сигилы/приёмы, раны/усталость, редко характеристики.

Валюта древа: **ОР**.

Узел древа даёт одно из:
1. +1 к мощи релевантного Квеля (потолок 10)
2. +1 ступень навыка по лестнице §3
3. аспект / сигил / приём / пассив
4. иногда +рана / +усталость / ступень характеристики

Профессии = короткие дороги к квелю + 2–3 навыкам.  
Потолки: слабый квель не держит пачку «зверей». Точные капы — в экономике древа (`v3/code`).

Старт: раса/фон + стартовые ОР (см. код экономики).

## 14. Памятка на карточку стола

1. Мой Квель ? Уровень цели ?  
2. Особое условие есть?  
3. Нет и Квель выше → **авто**  
4. Иначе → **к8** по моей ступени  
5. 1 и 8 взрываются
