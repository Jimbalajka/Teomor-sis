## ЗАФИКСИРОВАНО

### Термины / сила
- Нет классов, школ, профессий/суб-профессий.
- Вместо `+N`: **мастерство** (ступени).
- **Квель** = лига/фундамент (не класс).

### Структура карты (контент)
- **Одно целое древо** (не отдельные экраны/роуты на «доски»).
- Центр → **4 дара** → ветки из каждого дара.
- На дар: **гекс боевой** + **гекс социальный** (скилы/мастерство в кругах).
- На дар: **ромб боевых квелей** + **ромб социальных квелей** (не «профессии»).
- Аспекты/сигилы — отдельные пакеты позже, не смешивать случайно.
- Навык/характеристика + мастерство = **один круг**.
- Сейчас заглушки; гекс/ромб не переполнять (ориентир ≤4 узла на кольце).
- Раскладка: **ровные дуги по квадранту дара** (внутренняя = гексы, внешняя = ромбы), без случайного разброса.

### Раскладка / UX
- Cartesian / квадранты; не polar / не ZONE_ANGLE / не звезда.
- Только шоссе-рёбра; паутину `parentIds` скрывать.
- Главный критерий сдачи: **нет бардака, ничего не плывёт, ровно и красиво**.
- ~~Отдельный обзор + отдельная доска (старый вариант A)~~ — **снято**: целиком одно древо.

## ЧЕРНОВИК К УТВЕРЖДЕНИЮ 2026-09-27 — закрытый ответ, без уникальных подсчётов

### Боль автора
«Воин бьёт: квель ближнего 4 + мастер ближнего vs квель волшебника 4 + **что?**»  
Пока ответ открытый — каждый спор становится уникальной схемой. Это и есть белиберда.

Отказ от модели «+1 от оружия vs 1к6 уклонения» — это другая игра со своими костями.  
В Теоморе один бросок к8 и одна формула.

### Универсальный ответ (закрытый список)

У **атакующего** всегда два числа:
- квель дела (1–10)
- мастерство навыка, которым делает

У **цели** по умолчанию **одно** число — квель из закрытого списка.  
Не «квель волшебника + ещё что-то». Просто число ответа.

**Ровно 5 ответов на любого персонажа:**

| ответ | от чего работает |
|-------|------------------|
| Уклонение | удары, выстрелы, то что можно не поймать телом |
| Стойкость | захват, яд, удар которого не уклонился, грубая мощь |
| Сопротивление | магия, проклятия, сверхъестественное |
| Внимание | кража, скрытность, подвох, незаметный жест |
| Воля | страх, давление, приказ, ломание духа |

Действие **всегда** бьёт ровно в один ответ из пяти.  
Выбрал действие → снял число с листа цели → та же формула. Всё.

```
порог = сложность_мастерства + насколько_ответ_сильнее + условие
насколько_ответ_сильнее = max(0, квель_ответа − мой_квель)
```

Оружие, щит, сигилы **не** вводят вторую кости и не спрашивают «+ что».  
Они позже: условие / слой брони A·B / свойство приёма — но не новая схема спора.

### Примеры без уникальных схем

**Воин бьёт мага**  
мой: Ближний бой 6 + мастерство оружия «мастер»  
их: **Уклонение 3** (не «магия 4 + ?»)  
порог = 3 + 0 = **3**

**Маг жжёт воина**  
мой: Огонь 7 + школа «адепт»  
их: **Сопротивление 4**  
порог = 4 + 0 = **4**

**Кража у стража**  
мой: Воровство 5 + «ученик»  
их: **Внимание 6**  
порог = 6 + 1 = **7**

**Давление аурой**  
мой: Присутствие 8 + навык  
их: **Воля**  
Та же формула.

Маг с «квелем 4» без уточнения ответа в споре не участвует:  
в ударе важен не «он волшебник 4», а его **Уклонение** / **Сопротивление** / и т.д.

### Квель + мастерство — зачем оба
- квель = лига дела  
- мастерство = чистота исполнения → сложность к8  
У цели в обычном споре мастерство **не складываем** — только квель ответа.  
Так нет гонки «мастер уклонения + квель уклонения + бонус щита + …» на каждый удар.

Активный контрприём (парирование и т.п.) — позже как отдельный приём/сигил, не базовая схема.

### Статус
Закрытые 5 ответов + атака (квель+мастерство) vs один ответ — к утверждению.  
Это и есть универсальное представление: не таблица на всё, а 5 слотов на листе.
