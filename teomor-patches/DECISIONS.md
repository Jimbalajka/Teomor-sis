## ЧЕРНОВИК К УТВЕРЖДЕНИЮ 2026-09-27 — одна ось VS для всех бросков

### Отказ от двух осей
«Спор по квелю + отдельно аура/ранг героя» — снова две системы.  
Нужна **одна** проверка на любой бросок.

### Единое правило
Всегда одно и то же:

1. Берём **мой квель действия** (чем делаю).
2. Берём **их квель ответа** (чем сопротивляются этому действию).
3. Считаем порог. Кидаем к8 (или авто).

```
порог = сложность_ступени + насколько_ответ_сильнее + условие
```

- `насколько_ответ_сильнее` = их_квель_ответа − мой_квель_действия, но не меньше 0
- `условие` = 0 или 1
- **авто:** мой квель действия ≥ их ответ + 2, и условия нет
- если порог > 8 — голым навыком не взять

Сложность ступени (чем меньше — тем лучше):

| ступень | нужно ≥ |
|---------|---------|
| нет | 8 |
| новичок | 7 |
| ученик | 6 |
| эксперт | 5 |
| адепт | 4 |
| мастер | 3 |
| зверь | 2 |

КБ / броня в эту формулу не входят (слой A/B позже).

### Что против чего (примеры, одна ось)

| действие | мой квель | их квель-ответ |
|----------|-----------|----------------|
| ударить / пробить | удар / мощь | стойкость / защита |
| украсть / спрятаться | воровство / скрытность | восприятие / бдительность |
| надавить присутствием | аура / присутствие | воля / стержень |
| спор магией | магия (школа) | магия / сопротивление |
| взломать | взлом | охрана / восприятие |

**Аура — не вторая шкала.** Это обычный квель; в бросок идёт только когда действие — давление/присутствие.

### Зачем мультибилд
Лорно-сильный персонаж силён тем, что у него **высокие ответы в разных делах**.  
Ванкилл одного квеля бьёт только свой тип спора; в остальных его ломают чужие ответы.  
Сумма всех квелей в один бросок — нет.

Сигилы/черты позже могут подменять ответ или резать надбавку — как исключения к той же формуле, не как вторая ось.

### Статус
Единая ось «действие vs ответ» + формула порога — к утверждению автором.
