# Холодные / горячие — просто

Без столбцов «широкий/средний/жёсткий» и без арифметики пула.

## Два режима

**Холодный** — приём собран заранее.  
Занимает слот. В бою/сцене достаёшь быстро.

**Горячий** — собираешь сейчас.  
Слотов не занимает. Нужна **проверка навыка** (мастерство) + усталость сборки ≤ лимита квеля.

## Сколько холодных

На всего персонажа (все квели вместе):

| Аура | Холодных слотов |
|------|-----------------|
| 1–4 | **3** |
| 5–8 | **4** |
| 9–10 | **5** |

Всё. Под-лимитов на квель нет.  
Какие 3–5 холодных держать — выбор игрока (Тень, Слово, Волшба…).

Менять набор холодных — на отдыхе (короткий/длинный — по договорённости стола).

## Пример

Аура 3 → **3** холодных. Хоть все три тенью, хоть по одному из разных квелей.  
Горячий удар — слот не тратит; кинул проверку навыка, списал усталость.
