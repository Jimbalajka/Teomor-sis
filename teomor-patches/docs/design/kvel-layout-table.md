# Расклад квелей — 3+3 на дар (24 всего)

Каждый квель: ранги **1…10** (лимит усталости / мощи).  
Не классы — роли домена дара.

**Бой**
1. скорость
2. клинок / выстрел
3. тень

**Соц**
1. скольжение
2. обман жеста
3. побег / связь

3. механизм

**Соц**

2. сеть
3. алхимия / ремесло

3. строй

**Соц**

2. вера
3. лидерство
