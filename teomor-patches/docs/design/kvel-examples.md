# Примеры квелей (антикласс)

В каждом: ранг 1…10 → лимит по общей таблице; **одно разрешение режима**.  
Сигилы открывает дерево/навыки. Квель не монополит полку.

Лимит: 1→2, 2→4, 3→6, 4→9, 5→11, 6→13, 7→15, 8→18, 9→23, 10→30.

---

## 1. Запись
**Режим:** подготовка.  
**Разрешает:** собирать приёмы заранее и держать их в холодных слотах (число слотов = аура).  
**Не делает:** не выдаёт «школу мага» и не единственный путь к магическим сигилам.

## 2. Импульс
**Режим:** живой выпуск.  
**Разрешает:** собирать приём на месте (горячий): проверка навыка + усталость ≤ лимита.  
**Не делает:** не запрещает другим квелям магию/бой — только задаёт способ выпуска.

## 3. Упор
**Режим:** стойка.  
**Разрешает:** держать один активный приём-стойку (карта с тегом стойки); пока держишь — занимает холодный слот.  
**Не делает:** не класс бойца; стойки-сигилы могут прийти с разных веток дерева.

## 4. Канал
**Режим:** чужой источник.  
**Разрешает:** в сборке сигилы с тегом «внешний источник» (пакт, реликвия, чужая сеть).  
**Не делает:** не «класс колдуна» — тот же сигил мог бы требовать только тег, совместимый и с другим режимом позже.

## 5. Вшивка
**Режим:** железо/плоть.  
**Разрешает:** в сборке сигилы с тегом «вшитое»; инструмент-имплант (0) стыкуется без отдельного «класса».  
**Не делает:** не закрывает импланты только на себя, если дерево открыло сигил — нужен режим с этим свойством.

## 6. Связь
**Режим:** якорь/переход.  
**Разрешает:** сигилы с тегом «связь» (перемещение, метка места, канал к союзнику) в каскаде.  
**Не делает:** не профессия «портальщик»; тег могут использовать разные билды.

## 7. Перегруз
**Режим:** сверх лимита.  
**Разрешает:** собрать приём дороже лимита этого квеля ценой беклеша (провал → удар по себе).  
**Не делает:** не отдельный класс; обычно второй квель «на край», не единственный.

## 8. Контур
**Режим:** контроль каскада.  
**Разрешает:** в одном приёме на +1 сигил сверх обычного потолка от мастерства навыка (лимит усталости квеля всё равно держит).  
**Не делает:** не «билд контроллера» сам по себе — сигилы контроля с дерева.

## 9. Кость
**Режим:** тело как ресурс.  
**Разрешает:** платить **рану** вместо части усталости приёма (1 рана = фиксированный кусок усталости, число уточним).  
**Не делает:** не берсерк-класс; комбинируется с любыми сигилами, которые дерево открыло.

## 10. Эхо-матрица
**Режим:** след после приёма.  
**Разрешает:** сигилы с тегом «остаточный эффект» (короткий след после выпуска).  
**Не делает:** не школа «баффер»; только режим проводки эффекта.

---

## Как из этого собирается «свой класс» (не квель)

- «Уличный маг»: дар Медведя + навык волшебства + **Запись** или **Импульс** + сигилы с дерева.  
- «Железный боец»: дар Зюбания + **Вшивка** + **Упор** + сигилы имплантов/стоек с дерева.  
- «Тень»: дар Змея + навыки скрытности + **Импульс** или **Упор** + сигилы с дерева — **без** квеля «Тень».

Два квеля на персонаже — норма (например **Запись** + **Перегруз**).
