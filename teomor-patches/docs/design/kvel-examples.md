# Квели — формат автора + разбор

## Что думаю о твоих примерах

**Формат хороший.** Сразу ясно:
1) для чего полка  
2) какие сигилы  
3) одно конкретное свойство квеля  
4) лимит (стандарт / штраф / …)

Мои «режим / разрешает / не делает» — лишняя абстракция. **Запись** реально бесполезна: холодные слоты уже у всех от ауры. **Импульс** тоже пустышка, если горячий и так общий.

### Скорость — ок, с оговорками
- Полка «сигилы скорости» + свойство «действие вместо доп. действия» + **пониженный лимит (−1/−2…)** — читаемо и даёт цену за мощь.
- Осторожно: в Теоморе ещё нет жёсткой экономики «действие / доп. действие» как в D&D. Свойство надо сформулировать языком стола Теодора (иначе снова импорт PHB). Варианты смысла: лишний короткий приём; приём не занимает обычный «ход-действие»; один раз за раунд ускоренный выпуск.
- Риск класса: если *только* квель Скорости открывает эти сигилы и без него билд мёртв — снова класс. Лечится тем, что сигилы всё ещё требуют узел/навык дерева, а квель — ключ полки + свойство + лимит.

### Тень — ок как образец свойства
- «+1 рана, если урон из скрытности» + стандартный лимит — одна строка, без каши.
- Риск: плодится квель «на каждую фишку». Норма: у квеля **одна** такая строка, не список.

### Антикласс здесь
Не имя «Скорость/Тень» само по себе класс, а когда квель = единственный способ быть архетипом.  
Держим: **полка + 1 свойство + кривая лимита**. Фичи глубже — сигилы.

---

## Шаблон записи квеля

```
· Название
  Для чего: …
  Сигилы: полка «…» (req: этот квель ≥ N + узел дерева по необходимости)
  Свойство: одна механика
  Лимит: стандарт / −1 / −2 / …
```

Стандарт лимита: 1→2, 2→4, 3→6, 4→9, 5→11, 6→13, 7→15, 8→18, 9→23, 10→30.  
«−1 к лимиту» = на каждом ранге на 1 меньше (мин. 1).

## Примеры в твоём формате

· **Скорость**  
  Для чего: быстрые атаки, заклинания, короткие действия.  
  Сигилы: полка скорости.  
  Свойство: 1 раз за раунд можешь выпустить подходящий приём этой полки как ускоренный (не тратит обычное действие хода — формулировку экономики закрепим отдельно).  
  Лимит: −1 от стандарта (−2 на ранге 6+).

· **Тень**  
  Для чего: скрытые приёмы; удар непонятно откуда.  
  Сигилы: полка тени.  
  Свойство: если урон приёма идёт из скрытности — +1 рана.  
  Лимит: стандарт.

· **Железо**  
  Для чего: вшитые и протезные приёмы.  
  Сигилы: полка вшитого.  
  Свойство: 1 сигил полки можешь носить «вшитым» — не занимает холодный слот.  
  Лимит: стандарт.

· **Крушение**  
  Для чего: сила, пролом, захват, грубые приёмы.  
  Сигилы: полка мощи.  
  Свойство: успех приёма по укрытию/объекту ломает его на ступень сильнее.  
  Лимит: стандарт.

· **Расчёт**  
  Для чего: приёмы через слабость, разбор, точечный выброс.  
  Сигилы: полка расчёта.  
  Свойство: 1 раз за бой объяви слабость (Мастер ок) — следующий приём этой полки игнор одного мелкого условия.  
  Лимит: −1 от стандарта.

· **Обет**  
  Для чего: сила через клятву, чужой/священный канал.  
  Сигилы: полка обета (внешний источник).  
  Свойство: пока активен обет (1 формулировка на отдых) — холодный приём полки можно заменить горячим без слота, но провал = беклеш.  
  Лимит: стандарт.

· **Связь**  
  Для чего: перемещение, метка, канал к союзнику.  
  Сигилы: полка связи.  
  Свойство: 1 холодный приём полки можете делить с союзником в пределах короткой дистанции (он жжёт свой слот или ваш — выбрать при подготовке).  
  Лимит: −1 от стандарта.

· **Перегруз**  
  Для чего: рискованный выброс сильнее потолка.  
  Сигилы: любая полка (не своя монополия) — квель-модификатор каскада.  
  Свойство: можно собрать на 3 выше лимита; при провале проверки выпуска — беклеш (рана себе).  
  Лимит: −2 от стандарта (сам по себе слабый потолок, смысл в переплате).

---

## Вывод

Идём от **твоего** шаблона.  
Выкинуть квели, которые дублируют общее правило (холод у всех, горячий у всех).  
Оставить квели с **полкой + 1 свойством + лимитом (часто с штрафом за сильное свойство)**.
