# Разнообразие как в D&D — без кучи квелей и простыней

## Идея

Механики (рейтэй/Виэт, киборг, портents, щиты, рывки…) = **короткие сигилы + ключевые слова**.  
Квель = только **матрица** (лимит + 1 правило каскада).  
Архетип (скорость, тень, мощь…) = **тег**, какой пакет сигилов тебе открыт.

Не плодим квель «на каждую фичу».

---

## Три слоя

| Слой | Сколько | Что делает |
|------|---------|------------|
| **Квель-матрица** | мало (шт. 5–8 на всю игру) | лимит усталости + одно правило: стойки / живой каст / подготовка / пакт / кибер / тело… |
| **Архетип** | много ярлыков | не текст правил; ключ к полке сигилов («скорость», «тень», «имплант»…) |
| **Сигил** | много коротких карт | одна механика = одна карта, 1–2 строки |

Сборка как была: `Инструмент(0) → Квель → Аспект → Сигил(ы)`.

---

## Матрицы (мало, на всех даров хватает)

Примеры — не классы:

1. **Виэт / стойка** — можно держать ●-стойку; ●-сигилы
2. **Исток / подготовка** — сильные холодные
3. **Поток / живой** — горячий каст
4. **Пакт** — только сигилы покровителя
5. **Кибер** — импланты «на теле», протоколы
6. **Ярость / тело** — стойка цена/сила
7. **Портал / связь** — перемещение/связь как фокус

Дар решает, *какие архетипы и сигилы* тебе близки, не плодит свой набор матриц с нуля.

---

## Как переносить фичу D&D / рейтэй / киборг

| Было | В Теоморе |
|------|-----------|
| Class feature на полстраницы | **1 сигил** + тег архетипа + `req` матрица/ранг |
| Action Surge / рывок | сигил «Родник» / «Рывок» (● или приём) |
| Uncanny Dodge | сигил-реакция |
| Рейтэй-стойки | матрица Виэт + пакет ●-сигилов |
| Имплант-огнемёт | инструмент или сигил тега **кибер**, матрица Кибер |
| Пакт-цепь | матрица Пакт + сигилы покровителя |

Текст на карте: имя · стоимость · 1 строка эффекта · тег. Без лора в правилах.

---

## Архетипы зачем

Скорость / точность / тень / мощь… — это **полки**:  
взял архетип на дереве → открыл 5–10 сигилов полки.  
Квель не размножается: подключаешь полку к одной из матриц выше.

---

## Итог

- Квелей **мало** (матрицы).  
- Архетипов **много** (ярлыки).  
- Сигилов **много**, но каждый крошечный.  
Разнообразие = комбинаторика каскада + полки, не 40 уникальных квель-простыней.
