# Слои Теодора — анализ (факт / выдумка / дыра)

Виэт/рейтэй из рекомендации **убираю**. Это узкий подклассовый хвост playtest-карт, не ось системы.

---

## 1. Что реально зафиксировано

| Вещь | Статус | Где | Что даёт |
|------|--------|-----|----------|
| Аура 1…10 | зафиксировано | CORE / проверка | авто vs к8; **холодные слоты = аура** |
| Мастерство | зафиксировано | CORE / круг навыков | порог к8 (`5+их−моя`) |
| Дар (Змей/Медведь/Голубь/Зюбания) | на дереве | stub | ветка; мастерство хар-ки дара |
| Сборка карты | из player-rules + CORE | конструктор | `Инструмент(0) → Квель → Аспект → Сигил(ы)` |
| Квель: ранг → лимит усталости | таблица из player-rules, шкала 1…10 | CORE / catalog | потолок стоимости приёма |
| Ромбы «квели» на дереве | stub | skillTreeData | сейчас заглушки «Квель боя I…», **механики нет** |

Авто/к8 квель **не** считает. Оружие = инструмент, не квель.

## 3. Дыра (честно)

Нужно одно решение на вопрос:

**Что на дереве открывает доступ к сигилам / особенностям (рейтэй-штуки, кибер, алхимия…)?**

Варианты без поддакивания:

### A. Открывает квель
Ромб = квель. Ранг → лимит. Сигилы с `req: этот квель`.

- Плюс: совпадает со сборкой карты и со старым «квель обязателен».
- Минус: если назвать квели «волшебник / киборг / тень» → снова **классы**. Имена должны быть не профессиями, а доменами силы — и их нельзя раздувать до 40 простыней.

### B. Открывает отдельный узел «архетип»
Квель только лимит (+может быть пустой/общий). Полка сигилов с дерева архетипа.

- Плюс: квель не становится классом.
- Минус: второй тип узла; сборка «обязателен квель» начинает выглядеть искусственно («зачем квель в каскаде, если полку открыл другой узел»).

### C. Открывает навык / гекс (скил, черта)
Сигил `req: Ближний бой ≥ эксперт` или узел гекса.

- Плюс: меньше сущностей; дерево навыков уже есть.
- Минус: размывается роль квеля в каскаде; квель снова только «батарейка-лимит».

---

## 4. Что тогда в квеле — если не класс и не Виэт

Минимум, который уже следует из сборки и таблицы лимитов:

1. **Ранг → лимит усталости** (обязательно).
2. Место в каскаде: без квеля приём не собирается.

Всё остальное (стойки, импланты, «как в D&D») — **не обязано** жить в квеле. Это либо сигилы, либо узлы дерева — но **источник доступа к сигилам ещё не выбран** (A/B/C).

Тянуть узкий playtest-Виэт как ось — ошибка. Кибер/алхимия/тень как *полки эффектов* ок; как *классы-квели* — нет.

---

## 5. Практический вывод

- Архетипы сейчас = **только список имён в доке**, не механика.
- Квели на сайте = **заглушки**, не контент.
- Прежде чем писать 24 квеля или «полки», нужен выбор: **A / B / C** — кто даёт `req` на сигилы.

Без этого любой каталог снова будет кашей.
