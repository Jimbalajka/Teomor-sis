# Квели — переделка от таблицы лимитов (GitHub)

Источник лимита: `rpg-skill-tree-main/docs/player-rules.md` §1.1 (Лимит ОС).  
В v3 ОС на карте = **усталость приёма**. Шкалу ранга выпрямляем под итог 2026-09-27:  
**1 = ученик … 10 = верх** (старая «перевёрнутая» 10→1 здесь переложена 1:1).

## 2. Что даёт квель (без «придуманных путей»)

Из тех же player-rules, коротко:

1. **Лимит** — таблица выше.  
2. **Пассив / стойка** — одно свойство матрицы (ниже по каждому квелю).  
3. **Холодные слоты = аура** (1:1), см. `cold-hot-pools.md`. Под-лимитов на квель нет.  
4. **Сигилы** — карты с `req: этот квель ≥ N`. Списки не выдумываем до каталога карт.

**Холодные** занимают слоты пула. **Горячие** слотов не занимают — нужна проверка навыка + усталость ≤ лимита квеля.

## 3. Двадцать четыре квеля

У всех лимит = **только от ранга** (таблица §1). Ниже — пассив + тип холодных.

### Змей · бой

**Скорость** — стойка рывка: 1 свободное смещение 1 клетку / раунд.  
**Клинок/Выстрел** — оружейная матрица: базовая атака этим оружием без карты = 1 рана при успехе проверки.  
**Тень** — из укрытия первое раскрытие за сцену всегда с условием.

### Змей · соц

**Скольжение** — 1/сцену сменить круг общения без проверки.  
**Обман жеста** — при успехе жестового обмана цена провала следующего шага мягче (Мастер).  
**Побег/Связь** — 1/сцену путь отхода: авто по ауре при бегстве, если цель не выше вас на 4+.

### Медведь · бой

**Боевая волшба** — 1 боевой фокус аспекта / сцену без усталости. Холодные: **широкий**.  
**Расчёт** — 1/бой назвать уязвимость (Мастер ок) → следующий приём игнор одного мелкого условия.  
**Механизм** — 1 устройство-инструмент в сцене = 0 к усталости инструмента.

### Медведь · соц

**Знание** — 1/сессию один факт от Мастера в архиве/лабе по вашей теме.  
**Сеть** — в новом крупном поселении всегда есть контакт (имя Мастера).  
**Алхимия/Ремесло** — между сценами 1 расходник ранга ≤ потолка квеля.

### Голубь · бой

**Колдовство** — 1 метка/порча вне боя без усталости.  
**Подавление** — vs аура ниже вашей: первое давление воли / сцену без условия «на глазах».  
**Строй** — союзник рядом 1/раунд может принять удар за вас (раны).

### Голубь · соц

**Слово** — 1/сцену провал убеждения → успех ценой (цену говорит Мастер).  
**Вера** — исполненный обет при свидетелях → 1 Вдохновение (≤1/сессию).  
**Лидерство** — короткий приказ NPC с уровнем ≤ аура−2 без проверки (1/сцену на группу).

### Зюбания · бой

**Крушитель** — успех по объекту/укрытию разрушает сильнее на ступень.  
**Стойкость** — 1/бой −1 входящая рана (мин 0).  
**Имплант** — 1 имплант-сигил «на теле» не занимает слот холодной карты.

### Зюбания · соц

**Страх** — при входе в сцену, если аура ≥ цель+2: цель «сдержан» до одной проверки.  
**Статус силы** — в банде/казарме/арене первое впечатление как от ранга выше (не для боя).  
**Племя** — 1 «свой» за сессию может взять вашу ауру на одну проверку давления/духа.

## 4. Что сознательно выкинуто из прошлой версии

- Списки «сигилы-путь: рывок, зайчик…» — это был набор слов, не каталог.  
- «Лимит = ранг 1:1» — **нет**, есть таблица §1 с GitHub.  
- Путь квеля ≠ фанфик; путь = **под-лимит холодных** из player-rules §1.3.
