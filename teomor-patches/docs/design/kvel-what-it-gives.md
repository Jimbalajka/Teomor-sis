# Что даёт квель (не только название)

Квель **не** участвует в авто/к8 (это аура + мастерство).

## Всегда — у каждого квеля

1. **Потолок усталости приёма** — ранг 1…10 поднимает, сколько «веса» аспектов+сигилов можно собрать в приём этого квеля.
2. **Право собирать приёмы домена** — без квеля «Тень» нет приёмов тени в конструкторе.

## Уникальность квеля (то, чем они отличаются)

3. **Путь к уникальным сигилам** — сигил требует квель X ранга N.  
   Это главный морковь билда: качаешь квель → открываются свои сигилы → собираешь свои приёмы.
4. **Пассив / стойка** — короткое постоянное (или включаемое) свойство домена.  
   Не список «фич уровня», одна-две вещи на квель, усиливаются на порогах ранга (напр. 1 / 5 / 10).

## Чего квель не делает

- Не даёт +N к проверкам и не меняет ауру.
- Не выдаёт отдельную таблицу «условий на каждое действие» — условия сцены остаются у Мастера.
- Не класс: способности = **приёмы из сигилов под этим квелем**, а не ветка D&D-фич.

## Как звучит за столом

«У меня квель Тени 4» =
- могу собирать теневые приёмы до усталости 4;
- открыты сигилы Тени с req ≤4;
- работает пассив/стойка Тени своего ранга.

## Пороги ранга (простая сетка)

| ранг | что открывается |
|------|------------------|
| 1 | квель взят: пассив v1 + сигилы «старт» + лимит 1 |
| 2…4 | рост лимита + сигилы круга |
| 5 | пассив/стойка v2 + сигилы «ядром» |
| 6…9 | лимит + тяжёлые сигилы |
| 10 | пассив v3 / кэпстоун-сигил |

Итого: **лимит + гейт сигилов + пассив**. Способности — через сигилы/приёмы, не третьей параллельной системой.
