# Как делать квели, чтобы не стали классами

Архетипы тут ни при чём (только опора для имён у автора).

## Цель

Квель **не ограничивает профессию**, а **включает возможности**.  
«Уникальный класс» игрок собирает сам: дар + навыки + квель(и) + аспекты + сигилы + инструмент.

---

## Почему квель становится классом

Ломается, если верно хоть одно:

1. Имя = профессия (волшебник, вор, киборг-как-класс).
2. Только этот квель открывает «свои» сигилы, другие не могут.
3. Один квель = весь билдж (остальное дерева косметика).
4. Пассив квеля = длинный список фич как у subclass.

---

## Правило антикласса

**Квель отвечает на один вопрос: как ты проводишь силу в приём.**  
Не кем работаешь, не каким оружием, не какой лор-ролью.

В квеле только:

1. **Ранг → лимит** усталости приёма.  
2. **Одно разрешение** (что этот режим вообще позволяет в каскаде).  
3. По желанию — **одно ограничение режима** (цена свободы), не полка профессий.

Сигилы и «фичи как в D&D» — **отдельные карты**.  
Доступ к ним лучше вешать на **дерево** (дар / навык / узел), а квель в сборке проверяет: *этот приём вообще можно прогнать через такую матрицу?*

Итого:
- дерево / навыки → **что умеешь** (какие сигилы взял);
- квель → **через какой режим силы** это выпускаешь и какой потолок усталости;
- комбинация = твой «класс».

---

## Разрешение, не профессия (примеры режима)

Писать глаголами режима, не должностями:

| Режим квеля | Что разрешает | Не писать |
|-------------|----------------|-----------|
| Подготовка | держать холодные приёмы до лимита слотов ауры | «ты волшебник» |
| Живой выпуск | собирать горячий приём проверкой навыка | «ты чародей» |
| Стойка | держать один активный приём-стойку | «ты рейтэй» |
| Чужой канал | сигилы с тегом «внешний источник» | «ты колдун» |
| Железо/плоть | сигилы с тегом «вшитое» + инструмент-имплант | «ты класс Киборг» |
| Перегруз | сборка выше лимита ценой беклеша | — |

Игрок-«маг» = дар Разума + навык волшебства + сигилы огня + квель «подготовка» или «живой».  
Другой «маг» = те же сигилы, другой квель → другой класс по ощущению, без нового квеля-профессии.

---

## Перекрытие, не монополия

Если сигил вообще смотрит на квель — только на **свойство режима** (`нужен живой выпуск` / `нужно вшитое`),  
не на имя одного квеля-монополиста.

Один сигил — несколько совместимых квелей.  
Иначе снова класс.

Несколько квелей на персонаже — норма; «уникальный класс» часто = 2 режима + набор сигилов.

---

## Чего не делать в квеле

- Список из 8 способностей.
- «Только с мечом / только в тени».
- Уникальная полка сигилов без пересечений.
- Названия-профессии как единственный путь к механикам.

---

## Короткий чеклист автора квеля

1. Имя — про режим силы, не про job.  
2. Лимит по рангу — таблица.  
3. Одна строка: что **разрешает**.  
4. Сигилы этого «флейвора» открываются **деревом/навыком**, не эксклюзивом квеля.  
5. Два разных билда с этим квелем всё ещё выглядят по-разному (сигилы/дар/навыки).

Если пункт 5 провален — это класс, переделывать.
