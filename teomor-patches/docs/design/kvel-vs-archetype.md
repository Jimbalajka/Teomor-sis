# Квель vs архетип — кто что

## Короткий ответ

**Сигилы открывает квель** (как ты и предполагал).  
Архетипы (скорость, тень, киборг…) — это **имена/заготовки будущих квелей**, не отдельная полка рядом.

Не делаем два гейта: «архетип открыл сигилы» + «квель тоже открыл». Один гейт — **квель**.

---

## Что лежит в квеле (и только это)

1. **Ранг 1…10 → лимит** усталости приёма (таблица).  
2. **Одно правило матрицы** (строка): стойка / живой / подготовка / пакт / кибер / тело…  
3. **Полка сигилов** — сигилы с `req: этот квель ≥ N`.  

Не лежит в квеле: простыня фич как в D&D, привязка к мечу, сюжетные «раз за сцену».  
Фичи = **сигилы** на полке этого квеля.

---

## Примеры

| Ярлык | Это квель? | Внутри квеля |
|-------|------------|--------------|
| Скорость | да | лимит + матрица (напр. живой/стойка) + сигилы скорости |
| Тень | да | лимит + матрица + сигилы тени |
| Киборг | да | лимит + матрица «кибер» + сигилы имплантов |
| Волшебник / Исток | да | лимит + матрица «подготовка» + сигилы волшбы |
| Алхимик | да | лимит + матрица + сигилы алхимии |

Список архетипов в `gift-archetypes.md` — из него **выбираешь**, какие станут квелями на ромбах (3+3), остальные ярлыки не обязаны жить в правилах.

## Сборка

`Инструмент(0) → Квель → Аспект → Сигил(ы с req квеля)`  
Аура = холодные слоты. Горячий = проверка навыка.
