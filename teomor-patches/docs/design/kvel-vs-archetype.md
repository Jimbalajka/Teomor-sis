# Квель ≠ класс — критично

## Где я поддакивал зря

«Скорость / тень / киборг / волшебник / алхимик = квели, они открывают сигилы»  
→ это **классы**. Только название другое. В Теоморе классы запрещены.

Квель-волшебник + полка заклинаний = Wizard.  
Квель-киборг + полка имплантов = класс Киборг.  
Так нельзя.

---

## Развести слои (чтобы не классы)

**Квель** — *как* ты держишь силу (матрица), не *кем ты работаешь*.  
Мало штук на всю игру, имена операционные:

- Исток (подготовка)
- Поток (живой каст)
- Виэт (стойки ●)
- Пакт (чужой источник)
- Кибер-сеть (протоколы/на теле)
- Ярость (тело/цена)
- Портал (связь/фокус-переход)

Внутри квеля: **лимит по рангу** + **одно правило матрицы**.  
Не «ты вор», не «ты алхимик».

**Архетип** (скорость, тень, мощь, алхимия…) — ярлык на **дереве**.  
Открывает **полку сигилов**. Это не квель.

**Сигил** — одна короткая механика.  
`req`: архетип (или узел дерева) + часто **тип матрицы** (нужен Виэт / Кибер / Исток…), не «класс Тень 5».

---

## Как собирается

```
Инструмент(0) → Квель-матрица → Аспект → Сигил(ы с полки архетипа)
```

Пример: сигил «Рывок»  
- открыт архетипом **скорость** на дереве Змея  
- в сборке нужен квель **Виэт** или **Поток** (матрица), не «квель Скорости»

Киборгский огнемёт:  
- полка архетипа **имплант/кибер**  
- матрица **Кибер-сеть**  
не отдельный класс «Киборг» как квель-профессия.

---

## Кто что открывает

| | Открывает сигилы? | Что даёт |
|--|-------------------|----------|
| Архетип (дерево) | **да** — полку | доступ к картам |
| Квель-матрица | нет полкой «я класс» | лимит + правило каскада; иногда `req` типа матрицы |
| Сигил | — | сама механика |

Итог: разнообразие как в D&D сидит в **сигилах + архетипах**.  
Квель снова тонкий и не изображает профессию.
