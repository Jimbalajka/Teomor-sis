Сверь с твоим CORE.md из «Боту 1.pdf». Если расходится — приоритет у PDF.

## За столом
- Бросок: kN (≤3к20) + Куб Стиля (к6, не к сумме) + навык 0–15 vs Сложность
- Здоровье: только Раны (2→6)
- Защита: КБ = 10 + Уклонение + Броня
- Быстрая атака: kN vs КБ → 1 рана; приём → раны по Сигилу
- Усталость: впечатана на карте, считает приложение
- Свобода: манипуляция аспектом = сцена; мех. эффект vs слабых (−2 ур.) = авто; иначе проверка или приём
- Против PC — всегда защита

## Вне игры
- Древо → статы, аспекты, сигилы, квели
- Конструктор каскада → именованная карта; флавор пишет игрок
- Одна валюта прокачки древа: **ОР** (Очко Развития)
