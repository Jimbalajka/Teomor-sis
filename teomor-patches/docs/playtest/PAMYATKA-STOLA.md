# Памятка за столом — Teomor плейтест

**Бросок:** kN + Куб Стиля (к6) + Навык (0–15) vs Сложность.  
**Раны** 2→6 · **КБ** = 10 + Уклонение + Броня · быстрая атака = 1 рана.

**Фокус** (0 усталости) · **свободный эффект** · **приём** (карта).

**Аура:** цель −2 ур. → авто; ±1 и выше → бросок или приём; vs игрок → защита.

**Социалка:** язык слабого — авто; равного — «Глоссолалия»; приказ/истина — только приём; иллюзия — фокус; блеск клинка — авто на слабых; рентген — фокус.

1 клетка = 1,5 м. Каскад — только вне игры.
