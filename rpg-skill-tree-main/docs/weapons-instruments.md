# Теомор - Оружие и магические инструменты (пассивы)

В Теоморе **Инструмент = карта 0 ОС**: он НЕ даёт кубов урона (урон от Сигилов), а
задаёт **тип урона** и **пассивное свойство** всей сборки/атаки. Ниже пассивы для
всех видов оружия из книги + экзотика + магические инструменты. Черновик, правится.

Пассивы намеренно не все уникальны (некоторые повторяются - это нормально).

---

## 1. Простое рукопашное
| Оружие | Тип урона | Пассив |
|---|---|---|
| Боевой посох | Дробящий | Универсальное: держа двумя руками, +1 к КБ (парирование древком). |
| Булава | Дробящий | При Оглушении цель проходит спасбросок с -1. |
| Дубинка | Дробящий | Лёгкое: можно атаковать Быстрым действием раз за ход. |
| Кинжал | Колющий | Метательное; если цель тебя не видит - Сигил урона на ступень выше. |
| Копьё | Колющий | Досягаемость +1 клетка при упоре (не двигался в этот ход). |
| Лёгкий молот | Дробящий | Метательное; после броска можно сразу сменить оружие Малым действием. |
| Метательное копьё | Колющий | Дальний бросок; при попадании из движения +1 к пробитию. |
| Палица | Дробящий | Двуручное: игнорирует 1 брони. |
| Ручной топор | Рубящий | Метательное; на крит-успехе стиля - Кровотечение бесплатно. |
| Серп | Рубящий | Лёгкое; +1 к Сигилам, накладывающим Кровотечение. |

## 2. Простое дальнобойное

|---|---|---|
| Арбалет лёгкий | Колющий | Игнор половины укрытия, если не двигался. |
| Дротик | Колющий | Метательное, фехтовальное: дальность считается от Моторики. |

| Праща | Дробящий | Дёшево и тихо: выстрел не раскрывает скрытность при промахе. |

## 6. Магические инструменты (0 ОС, пассив)
Инструмент задаёт природу магии (наука/чутьё/дар) и правило сборки.

| Инструмент | Пассив |
|---|---|
| Палочка | +1 к Быстрому действию (холодные касты); Аспекты дешевле на 1 (мин 0), но лимит Квеля не выше 3 ранга. |
| Посох | +1 слот Сигила сверх лимита Квеля; двуручный, высокая ёмкость ОС. |
| Книга (Гримуар) | +2 к рабочей руке холодных; нужна свободная рука; сборка «живого» чуть дольше. |
| Хрустальный шар | +2 дальности всем Сигилам; раз за сцену - «взгляд» (разведка/прорицание). |
| Волшебный кристалл | Хранит 1 заряженную сборку; выпустить её Быстрым действием, затем перезарядка. |
| Скипетр | Аура командования: союзники в 3 клетках +1 к спасброскам; символ власти. |
| Руки (голая магия) | Нет штрафа за занятые руки; сырой каст без Аспекта +2 к урону, но грубее контроль. |
| Амулет/Символ | Раз за сцену поглощает беклеш (без Истощения); преимущество на удержание концентрации. |
| Маска | Меняет тип урона Аспекта на «за-масочный» раз за бой; +к устрашению/иллюзии. |
| Бубен/Инструмент (бард) | Звуковые Сигилы бьют по площади; можно кастовать без вербальных компонентов. |
| Рунные оковы/кандалы | Инструмент колдуна: усиливают Сигилы контроля (Опутывание/Оглушение). |
| Татуировки/Печати на теле | Всегда «в руке», нельзя обезоружить; но набор Аспектов фиксирован при нанесении. |
| Тотем/Идол | Ставится на клетку: аура эффекта Квеля в радиусе, пока стоит (жрец/друид). |
| Фокус-линза | +к дальнобойным Сигилам-лучам (линия); фокусирует урон в одну цель. |
