# Способность → узел / карта / фокус / черта

Три персонажа плейтеста. **ОР:** 4 старт + 2/ур. → ур.14 ≈ 30, ур.15 ≈ 32.

Легенда: **У** = узел древа · **К** = карта (приём) · **Ф** = фокус (0 усталости) · **Ч** = черта

## Общие правила перевода

| D&D привычка | Teomor v2 |
|--------------|-----------|
| Spell slot | Усталость на карте; приложение считает |
| Cantrip | Фокус или быстрая атака (1 рана) |
| Save DC | Сложность = 10 + навык или уровень мастера |
| AC | КБ = 10 + Уклонение + Броня |
| HP | Раны 2→6, быстрая атака = 1 рана |
| Auto на слабых | Аура: цель на 2+ ур. ниже — без броска |
