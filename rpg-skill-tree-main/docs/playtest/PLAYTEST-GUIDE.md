# Плейтест — что делать (4 дня в одном месте)

## Перед игрой

1. Скопируй `day1-bundle/app/src/` → свой `app/src/` (или весь бандл).
2. `npm install && npm run build && npm run dev` — открой на **телефоне** в одной Wi‑Fi.
3. Распечатай: **CORE-ONEPAGE.md** + **PAMYATKA-STOLA.md** + **SHEET-PRINT.md**.
4. Каждый открывает **ABILITY-MAP.md** — свой блок, прокликивает древо.

## Кто что трогает

| | В приложении (телефон) | На бумаге |
|---|------------------------|-----------|
| Древо, ОР | ✓ | — |
| КБ, раны, усталость | ✓ Sidebar | ✓ клетки запас |
| Карты | ✓ вкладка Карты | ✓ названия своими словами |
| Бросок kN+к6 | **живые кости** | — |
| История, диалоги | — | ✓ |

## День 4 — сценарий мастера

**Социалка (20 мин):** рынок → примеры 1–3 из CORE-ONEPAGE (язык, торг, вспышка на толпе).

**Бой (15 мин):** 2 гоблина (ур. 5, КБ 12, 2 раны) + 1 «равный» (ур. 14, КБ 16).  
Проверить: быстрая атака, приём с усталостью, аура на слабых.

**После:** баги в Issues / сообщение в чат — что неудобно на телефоне.
