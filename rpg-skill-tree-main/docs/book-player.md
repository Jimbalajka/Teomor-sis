# ТЕОМОР — Книга Игрока (правила)

Только правила. Сухо. Лор — отдельно. Термины со * есть в Словаре (в конце).

---

## 1. Проверка
```
kN + Куб Стиля(к6)  против  Сложности (1–100)
```
- **kN** (Кость Действия*) + модификатор ≥ Сложности → успех.
- Куб Стиля* к числу **не** прибавляется (см. §2).
- **Не кидай**, если Сложность < среднего (kN + мод): авто-успех, кидается только Куб Стиля.
- Нет владения навыком → бросок с **помехой** (2 кубика, берёшь худший).
- Сложность ставит Мастер: 1 — тривиально, 100 — божественно.

kN по уровню: к6 → к8 → к10 → к12 → 2к6 → 2к8 → 3к6 → 3к8 → 4к8 → … → 10к10.

---

## 2. Куб Стиля и криты
Куб Стиля (к6) задаёт «как» вышло. Взрывается на 1 и 6 (переброс).
- Чёт (2,4,6) — благоприятно. Нечёт (1,3,5) — с помехой.
- **6+6** — Крит Успех (двойное Вдохновение*).
- **6+1** — успех, но хаос (без Уныния*).
- **1+6** — провал смягчён, смерть исключена (без Вдохновения).
- **1+1** — катастрофа: травма/смерть, двойное Уныние.
- 6 → Вдохновение (+1). 1 → Уныние (+1).

---

## 3. Вдохновение / Уныние (макс 3 каждого)
**Вдохновение** (тратит игрок, свободное действие):
- +1 ступень kN на бросок · снять ранение · отменить 1 Уныние · обменять на 6 Куба Стиля.
- 3 жетона → крит успех.

**Уныние** (тратит Мастер):
- −1 ступень kN игрока · +половина к стоимости способности · ранение · −на Куб Стиля.
- 3 жетона → крит провал.

Сбрасываются после длинного отдыха. Друг друга не отменяют (кроме траты Вдохновения).

---

## 4. Характеристики
Четыре: **Мощь, Разум, Моторика, Стержень**. Старт **−2**. Диапазон −10…+10 (баффы до ±20).
- Растут: +1 за уровень (выбор) + бонусы уровней пути + черты.
- **Потолок по рангу Квеля*:** Квель 10 → +3 · 9–8 → +5 · 7–5 → +8 · 4–1 → +10.
- **Лимит навыка:** владеешь → бонус навыка ≤ ×2 характеристики; не владеешь → ≤ половины.

---

## 5. Навыки (по характеристикам)
- **Мощь:** Здоровье(кость), Атлетика(кость), Выживание, Ближний бой, Запугивание, Импланты.
- **Разум:** Гум. наука, Точная наука, Безумная наука, Медицина, Анализ, Поиск информации,
  Природа, Ремонт, Хакерство, ЭлектроМех, Волшебство, Мистика, Алхимия.
- **Моторика:** Акробатика(кость), Уклонение(кость), Судовождение, Вождение, Пилотирование,
  Верховая езда, Скрытность, Воровские навыки, Ловкость рук, Ближний бой, Дальний бой, Печати.
- **Стержень:** Убеждение, Запугивание, Обман, Выступление, Лидерство, Дрессировка, Внимание,
  Проницательность, Интуиция, Колдовство, Псионика.

Магия по характеристикам: Волшебство/Мистика/Алхимия → Разум; Колдовство/Псионика → Стержень.

---

## 6. Защита, здоровье, раны
- **КБ** (Класс Брони) = Уклонение + Выживание + 10 (+ броня/щиты/магия). До 100.
- **Порог** (= Хиты) = Выживание + **максимум** Кости Здоровья.
- Атака: kN + мод против КБ. Пробил → урон сравнивается с Порогом.
- Урон **≥ Порога** → **Рана**. Старт 2 раны, до 6 (навыками). Раны кончились → крит. состояние/смерть.
- Броня может работать как редукция урона (вычет), если так указано на предмете.

---

## 7. Бой
Ход: **1 Действие + 1 Бонусное + 1 Малое + 1 Реакция**.
- Атака / сборка каскада* / сложный каст = **Действие**.
- Способность за 0 ОС* = Бонусное. Мелкое перемещение/поднять предмет = Малое.
- **Инициатива** — карточная (раздача колоды на раунд).
- Сетка: **1 клетка = 5 футов**.

---

## 8. Способности: Квель / Аспект / Сигил
Любая способность = каскад* карт на Квеле*, собирается за Действие (~6 сек).

| Карта | ОС* | Роль |
|---|---|---|
| **Инструмент** | 0 | Оружие/фокус. Тип урона + пассив. |
| **Квель** | — | Фундамент. Лимит ОС, ранг, пассив/стойка. |
| **Аспект** | 1 | Тип урона. Базовый = только урон (без состояний). |
| **Сигил** | 1+ | Урон / форма (конус, зона) / эффект-состояние. |

- Стоимость сборки ≤ **лимит ОС** Квеля.
- **Лимит Сигилов** = значение магнавыка (Волшебство/Колдовство/Псионика…): +1→1, +2→2…
- **Каст сверх лимита ОС:** спасбросок, Сложность = ОС(сверх)×2 + ОС(итог) + ранг Квеля. Провал → беклеш*.
- Состояния навешивают **Сигилы** (не Аспекты).
- **Воин:** тип урона от Инструмента; Аспекты доступны только с зачарованием/владением.

**Ранги Квеля и лимит ОС** (шкала инвертирована 10→1):
| Уровни | Ранг | Лимит ОС |
|---|---|---|
| 1–3 | 10 | 2–3 |
| 4–7 | 9–8 | 4–7 |
| 8–11 | 7–6 | 9–12 |
| 12–15 | 5–4 | 13–16 |
| 16–20+ | 3–1 | 18–30+ |

**Горячие vs Холодные:**
- Горячие (живые) — собираешь в бою, полный эффект, тратят Действие, дороже.
- Холодные (подготовленные) — быстрый ввод (Бонусное), слабее (−кость/−спасбросок), «морозят» часть пула ОС.
- **Память** и **рабочая рука** — общие на персонажа (не на каждый Квель); путь Квеля задаёт под-лимит.

---

## 9. Состояния (базовые)
Накладываются Сигилами. Не привязаны к стихии.
1. **DoT** (Горение/Кровотечение/Отравление) — урон в начале хода / при движении.
2. **Оглушение** — пропуск хода, нет реакций/концентрации.
3. **Ослепление** — штраф к атаке, уязвимость, нельзя целиться вдаль.
4. **Замедление/Опутывание** — −скорость вплоть до обездвиживания.
5. **Истощение/Слабость** — штраф к урону/сопротивлениям.
6. **Обезоруживание** — потеря бонусов Инструмента.
7. **Ошеломление** — помеха на ментальные спасброски, блок сложных Сигилов.

---

## 10. Отдых
- **Короткий** — восстанавливает половину показателей (хиты, ресурсы), пересбор колоды.
- **Длинный** — всё к максимуму; сбрасывает Вдохновение/Уныние.

---

## 11. Создание персонажа
1. Раса (десы / джухдесы / сфериды) — даёт особенности и бонусы.
2. Предыстория — владения навыками (не характеристиками).
3. Все характеристики стартуют с −2.
4. Стартовый капитал: **2 ОУ*** и **2 ОО***.
5. Недостатки: до 3, каждый даёт +1 ОО (по книге).

---

## 12. Развитие (древо навыков)
Классов нет — билд собирается из древа.
- **ОУ (Очки Умений):** Дары и уровни путей. Старт 2, **+1/уровень**.
- **ОО (Очки Опыта):** транзитные навыки, суб-профессии. Старт 2, **+1/уровень**.
- **Очки характеристик:** +1/уровень (в центр), потолок по рангу Квеля.

| Действие | Цена | Требование |
|---|---|---|
| Открыть Дар (специализацию) | 2 ОУ | 1 уровень |
| Повысить путь (до 10) | 1 ОУ | — |
| Школа (Волшебство и т.п.) | 1 ОУ | путь ур.1 |
| Суб-профессия | 1 ОО | путь ур.3 |
| Транзитный навык | 1 ОО | родитель изучен |
| Черта (слот слева) | 1 ОО | 1 раз / 4 уровня |
| Ремесло/владение (справа) | 1 ОО | 1 раз / 4 уровня |

- 4 Дара: **Медведя** (Магия/Разум), **Зюбания** (Ближний бой/Мощь), **Змея** (Ловкость/Моторика),
  **Голубя** (Мудрость/Стержень).
- При выборе профессии — выбор **аспекта** + **2 сигилов** из 4.
- **Секретные** узлы — скрыты, открываются по условию.

---

## 13. Инвентарь
- Слотов = **10 + Мощь**. Крошечное 0 · малое 1 · среднее 2 · крупное 3–4.
- Экипированное место не занимает. Перегруз → нет Быстрого действия и Рывка.

---

## 14. Словарь терминов
- **kN / Кость Действия** — основная кость проверки (к6…10к10), растёт с уровнем.
- **Куб Стиля** — к6, бросается с каждой проверкой; задаёт качество исхода и криты.
- **ОС (Очки Силы)** — «топливо» способностей (мана/выносливость). Лимит задаёт Квель.
- **Квель** — фундамент способности; лимит ОС, ранг (10 ученик → 1 бог), пассив/стойка.
- **Аспект** — тип урона (огонь, лёд, психический…).
- **Сигил** — эффект: урон/форма/состояние.
- **Каскад** — собранная из карт способность (Квель + Аспект + Сигилы).
- **Беклеш** — обратный удар по кастеру при провале переклада энергии.
- **Порог / Хиты** — сколько урона держишь до Раны.
- **Рана** — тяжёлое повреждение; лимит 2→6.
- **ОУ / ОО** — Очки Умений (Дары) / Очки Опыта (транзит).
- **Дар** — специализация (одна из 4 веток древа).
- **Путь** — уровень специализации (1–10) и её школы.
- **Вдохновение / Уныние** — мета-ресурсы игрока / Мастера (макс 3).
- **Ранг Квеля** — 10…1 по уровню; задаёт лимит ОС и потолок характеристик.
