# Миграция на Ядро v2 — что переносим, что режем, план

Опора: `docs/core/CORE.md`. Старые доки остаются как справка; сюда — что живёт дальше.

## 1. Переносим без изменений (не сломано, ложится в новое ядро)
- **Расы** (`app/src/races.ts`) — десы/джухдесы/сфериды + выборы расы.
- **Предыстории** (`app/src/backgrounds.ts`) — владения навыками.
- **Пассивы оружия/инструментов** (`docs/weapons-instruments.md`) — тип урона + пассив (0 ОС уже вписан).
- **Состояния** (7 базовых) — переезжают как эффекты Сигилов.
- **Категории карт** (Квель/Аспект/Сигил/Инструмент) и вкладка Карты.
- **Структура древа**: Дары → школы → суб-профессии → Перо; слоты Черт/Ремёсел.
- **Таксономия профессий** (Волшебство/Мистика/Ремесленник; Колдовство/Псионика/Божественное; и т.д.).
- **PoE-ноды** (`docs/skill-nodes-poe.md`) — как идея наполнения.
- **UI**: конструктор карт, лист персонажа, редактор древа, всплывающие окна (создание персонажа).

## 2. Убираем (лишний счёт / противоречит ядру)
- **Подсчёт ОС за каст** и лимит ОС «на лету» → цена приёма впечатана (Усталость), считает приложение.
- **Лимит Сигилов = значение навыка** (жил за столом) → убираем; ограничение = ранг Квеля при СБОРКЕ.
- **Спасбросок перелимита (DC-формула)** → убираем.
- **Память / заморозка пула / рабочая рука** (микроменеджмент) → убираем; вместо — Усталость.
- **Порог/Хиты числовой, урон в HP** → только **Раны**.
- **Двойная валюта ОУ/ОО** → одна валюта (**ОР — Очко Развития**).
- **База характеристик −2, кости-навыки (Здоровье/Атлетика/Уклонение как кость)** → навыки = +0…15,
  навык «Здоровье» убрать (здоровье = Раны).
- **kN до 10к10** → максимум 3к20 (+4к20 эндгейм).
- **Живой каскад как основной режим боя** → каскад только в подготовке (конструктор).

## 3. Изменяем
- **Валюта древа:** ОУ+ОО → **ОР** (одна). Цена узла на самом узле.
- **Характеристики/навыки:** 0…15, потолок по рангу Квеля, +5 артефакты, кап 20.
- **Защита:** КБ = 10 + Уклонение + Броня (Выживание из формулы убрано).
- **Урон:** только Раны (базовая 1 / приём 2+ / крит +1).
- **Новое: Аура** — правило авто-эффекта против цели на 2+ уровня ниже (см. CORE §4).
- **Новое: Усталость** — трек, впечатанная цена приёмов.
- **Классовый стиль каста** — Волшебник (речь/модульно) vs Чародей-Колдун (молча/стихии).

## 4. Древо навыков под новое ядро
- Узлы двух ролей: **пассив** (+навык/статы 0-15, +Раны, +КБ, +Аура-порог) и **открытие**
  (Аспект / Сигил / Квель / слот приёма).
- Убрать со узлов модификаторы «+Лимит ОС» (ОС больше не считается за столом) → заменить на
  «+1 деление Усталости-пула» или пассивные Сигилы.
- Одна валюта **ОР** на всё; цена на узле.
- Суб-профессии: окно выбора Аспект + Сигилы остаётся, но результат **питает конструктор**
  (открывает эти карты в коллекцию), а не считает ОС.
- Слоты Черт (слева) / Ремёсел (справа) — оставить (1 за 4 уровня).
- Кейстоуны/ноутейблы (PoE-док) — наполнять.
