# Симулятор баланса «Теомор»

```bash
python3 sim/balance.py     # печатает отчёт + пишет sim/balance-report.md
```

Считает ядро БЕЗ полной колоды: кости/проверки, Куб Стиля, урон vs Порог ран,
экономику ОС, каст сверх лимита. Черновые карты закодированы в `balance.py`
(`DAMAGE_SIGILS`, `ASPECTS`, `TIERS`) - заменяй/дополняй по мере готовности колоды.

## Как датамайнить всю колоду (когда карты будут)
1. Каждая карта = объект: {тип, цена ОС, кубы урона / эффект, требования}.
   Держать в JSON (тот же формат, что и в приложении).
2. Скрипт перебирает допустимые сборки в рамках (лимит ОС + лимит сигилов) на тир.
3. Для каждой сборки Монте-Карло: средний урон, P(рана), урон/ОС, покрытие целей.
4. Сортировка -> топ (потенциальная мета) и низ (мёртвые карты).
5. Флаг: если одна связка бьёт по урон/ОС остальные на >X% - дисбаланс.

Сейчас `balance.py` делает шаги 2-4 на упрощённой модели дамп-урона; расширяется
до полной колоды добавлением карт в словари.

## Ключевые находки (последний прогон)
- **Куб Стиля стабилен**: «Ура» 16.6% / двойной крит 2.7% на всех тирах. ✅
- **Правило порога броска (#3) работает**: у цели ~уровня шанс ~50-65% везде. ✅
- **Каст сверх лимита ОС**: новичок не может (0%), мастер (Квель 3-1) почти всегда
  (99-100%). Формула DC = сверх×2 + ОС + ранг Квеля - точно бьёт в замысел. ✅
- **Маржа сигила линейна** (+4.5 за 1к8), экспоненты нет - дамп управляем. ✅
- ⚠️ **ПРОБЛЕМА: чистый урон-дамп умирает на поздних тирах.** Порог ран
  противников растёт быстрее, чем дамп из одинаковых 1к8 (P(рана) падает до 0% на
  4к8+). Причина: сигилы урона в модели не растут в РАЗМЕРЕ кости, только в
  количестве. **Фикс:** поздние сигилы урона должны давать 1к10/1к12 (а не пачку
  1к6/1к8), и/или сгладить кривую Порога ран. Иначе путь «тупого урона» (#12)
  перестаёт работать к эндгейму - придётся полагаться только на комбо/бронебойность.
